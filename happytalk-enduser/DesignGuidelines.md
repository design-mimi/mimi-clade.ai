# 문의 화면 구현 가이드

## 1. 목표
피그마 확정 디자인 기준으로 문의 관련 화면을 빠르게 구현한다.  
이번 구현의 목표는 다음 3가지다.

1. 피그마 디자인과 최대한 동일하게 구현
2. 홈 화면은 variant 방식으로 재사용 가능하게 구성
3. 메시지/설정 화면은 공통 구조로 단순하게 구현

---

## 2. 화면 범위

### 홈
- 홈 / 브랜드 이미지형
- 홈 / 그라데이션 직선형
- 홈 / 그라데이션 오벌형 (원형그라데이션)
- 홈 / 기본형

### 메시지
- 메시지 리스트
- 채팅 화면

### 설정
- 설정 화면

---

## 3. 구현 원칙

### 원칙 1. 홈만 variant 처리
홈 화면만 디자인 차이가 있으므로 variant 방식으로 구현한다.

예:
- `home-brand-image`
- `home-gradient-line`
- `home-gradient-oval` 
- `home-circle`
- `home-default`

### 원칙 2. 메시지/설정은 공통 구조
메시지와 설정은 디자인 variation을 두지 않고 단일 구조로 구현한다.

### 원칙 3. 공통 컴포넌트 우선
화면 단위로 바로 만들지 않고, 공통 컴포넌트를 먼저 만든 뒤 조합한다.

### 원칙 4. 피그마 값 직복사 금지
반복되는 값은 토큰으로 정리해서 사용한다.
- spacing
- radius
- color
- typography

### 원칙 5. 이번 단계에서는 자동화 배제
- DESIGN.md 자동 해석
- 테마 자동 생성
- 스토리북 맞춤 작업
모두 제외한다.

지금 단계에서는 구현 정확도와 속도가 우선이다.
시안 대로 구현율 가장 높이는 것이 너의 목표.
